# 🧠 DevBrain - Ultimate DevOps & Developer Productivity Dashboard

## 🎯 Project Vision

## 🏗️ TECHNICAL ARCHITECTURE

### Tech Stack

#### Frontend
- **Framework**: Next.js 14+ (App Router)
- **Language**: TypeScript
- **UI Library**: React 18+
- **Styling**: Tailwind CSS + shadcn/ui
- **State Management**: Zustand + TanStack Query
- **Charts**: Recharts / Chart.js / Apache ECharts
- **Terminal**: xterm.js
- **Code Editor**: Monaco Editor (VS Code engine)
- **Forms**: React Hook Form + Zod
- **Tables**: TanStack Table
- **Animations**: Framer Motion

#### Backend
- **Runtime**: Node.js (Next.js API Routes + tRPC)
- **Language**: TypeScript
- **API**: tRPC for type-safe APIs
- **Real-time**: Socket.io / Server-Sent Events
- **Authentication**: NextAuth.js / Clerk
- **ORM**: Prisma / Drizzle ORM
- **Background Jobs**: BullMQ + Redis
- **Task Scheduler**: node-cron
- **SSH Client**: ssh2 (Node.js)
- **Server Monitoring**: node-os-utils, systeminformation

#### Database
- **Primary DB**: PostgreSQL (with pgvector for AI)
- **Cache**: Redis
- **Time-Series**: TimescaleDB (PostgreSQL extension)
- **Document Storage**: MongoDB (optional, for logs)

#### Infrastructure
- **Hosting**: Vercel (Frontend) + VPS (Backend services)
- **Storage**: S3-compatible (Cloudflare R2 / AWS S3)
- **CDN**: Cloudflare
- **Monitoring**: Prometheus + Grafana
- **Logging**: Winston + Loki
- **Container**: Docker + Docker Compose

#### AI/ML
- **LLM Integration**: OpenAI API / Anthropic Claude API
- **Vector DB**: Pinecone / Qdrant
- **Local Models**: Ollama (optional)

#### Mobile (Android)
- **Framework**: React Native / Flutter
- **Language**: TypeScript / Dart
- **State**: Redux Toolkit / Riverpod

## 🗄️ DATABASE SCHEMA

### Core Tables

```prisma
// User & Auth
model User {
  id            String    @id @default(cuid())
  email         String    @unique
  name          String?
  password      String?   // hashed
  role          Role      @default(USER)
  createdAt     DateTime  @default(now())
  updatedAt     DateTime  @updatedAt

  servers       Server[]
  websites      Website[]
  tasks         Task[]
  apiKeys       ApiKey[]
}

enum Role {
  ADMIN
  DEVELOPER
  VIEWER
}

// VPS Servers
model Server {
  id            String    @id @default(cuid())
  name          String
  host          String
  port          Int       @default(22)
  username      String
  authMethod    AuthMethod @default(SSH_KEY)
  privateKey    String?   // encrypted
  password      String?   // encrypted
  status        ServerStatus @default(OFFLINE)
  lastCheck     DateTime?
  userId        String
  user          User      @relation(fields: [userId], references: [id])

  metrics       ServerMetric[]
  deployments   Deployment[]
  services      Service[]
}

enum AuthMethod {
  SSH_KEY
  PASSWORD
}

enum ServerStatus {
  ONLINE
  OFFLINE
  ERROR
}

// Server Metrics (Time-Series Data)
model ServerMetric {
  id            String    @id @default(cuid())
  serverId      String
  server        Server    @relation(fields: [serverId], references: [id])

  cpuUsage      Float
  memoryUsage   Float
  diskUsage     Float
  networkIn     Float
  networkOut    Float

  timestamp     DateTime  @default(now())

  @@index([serverId, timestamp])
}

// Websites
model Website {
  id            String    @id @default(cuid())
  name          String
  url           String
  serverId      String?
  status        WebsiteStatus @default(UNKNOWN)
  sslExpiry     DateTime?
  lastCheck     DateTime?
  userId        String
  user          User      @relation(fields: [userId], references: [id])

  uptimeChecks  UptimeCheck[]
  deployments   Deployment[]
}

enum WebsiteStatus {
  UP
  DOWN
  DEGRADED
  UNKNOWN
}

model UptimeCheck {
  id            String    @id @default(cuid())
  websiteId     String
  website       Website   @relation(fields: [websiteId], references: [id])

  responseTime  Int       // milliseconds
  statusCode    Int
  isUp          Boolean
  timestamp     DateTime  @default(now())

  @@index([websiteId, timestamp])
}

// Deployments
model Deployment {
  id            String    @id @default(cuid())
  websiteId     String
  website       Website   @relation(fields: [websiteId], references: [id])
  serverId      String
  server        Server    @relation(fields: [serverId], references: [id])

  branch        String
  commit        String
  status        DeploymentStatus
  startedAt     DateTime  @default(now())
  completedAt   DateTime?
  logs          String?   @db.Text

  @@index([websiteId, startedAt])
}

enum DeploymentStatus {
  PENDING
  IN_PROGRESS
  SUCCESS
  FAILED
  ROLLED_BACK
}

// Services (Nginx, MySQL, etc.)
model Service {
  id            String    @id @default(cuid())
  serverId      String
  server        Server    @relation(fields: [serverId], references: [id])

  name          String
  type          ServiceType
  status        ServiceStatus
  port          Int?
  autoRestart   Boolean   @default(false)
  lastCheck     DateTime?
}

enum ServiceType {
  NGINX
  APACHE
  MYSQL
  POSTGRESQL
  REDIS
  DOCKER
  NODE
  PM2
  OTHER
}

enum ServiceStatus {
  RUNNING
  STOPPED
  ERROR
}

// API Keys for external integrations
model ApiKey {
  id            String    @id @default(cuid())
  name          String
  key           String    @unique
  userId        String
  user          User      @relation(fields: [userId], references: [id])

  lastUsed      DateTime?
  createdAt     DateTime  @default(now())
  expiresAt     DateTime?

  @@index([key])
}

// Tasks (TrovaTask integration)
model Task {
  id            String    @id @default(cuid())
  title         String
  description   String?   @db.Text
  status        TaskStatus @default(TODO)
  priority      Priority  @default(MEDIUM)
  userId        String
  user          User      @relation(fields: [userId], references: [id])

  dueDate       DateTime?
  createdAt     DateTime  @default(now())
  updatedAt     DateTime  @updatedAt
}

enum TaskStatus {
  TODO
  IN_PROGRESS
  DONE
  CANCELLED
}

enum Priority {
  LOW
  MEDIUM
  HIGH
  URGENT
}

// Knowledge Base
model KnowledgeEntry {
  id            String    @id @default(cuid())
  title         String
  content       String    @db.Text
  category      String
  tags          String[]

  createdAt     DateTime  @default(now())
  updatedAt     DateTime  @updatedAt

  @@index([category])
}

// Notifications
model Notification {
  id            String    @id @default(cuid())
  userId        String

  type          NotificationType
  title         String
  message       String    @db.Text
  read          Boolean   @default(false)

  createdAt     DateTime  @default(now())

  @@index([userId, read])
}

enum NotificationType {
  INFO
  WARNING
  ERROR
  SUCCESS
}
```

## 🔒 SECURITY CONSIDERATIONS

1. **Data Encryption**
   - Encrypt SSH keys & passwords at rest
   - Use AES-256 encryption
   - Secure key management (env variables)

2. **Authentication**
   - JWT tokens with short expiry
   - Refresh token rotation
   - Rate limiting on auth endpoints

3. **API Security**
   - API key authentication
   - CORS configuration
   - Input validation & sanitization
   - SQL injection prevention (ORM)

4. **Infrastructure**
   - HTTPS only
   - Security headers (CSP, HSTS)
   - Regular dependency updates
   - Automated vulnerability scanning
